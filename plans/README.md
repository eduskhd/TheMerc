## Recommended execution order

```
001 → 002 → 003 → 005 → 004
```

**Rationale:**

- **001 first** — Replacing `transition: all` on buttons makes the `transition-property` overrides in plan 003 more precise. Execute before 003.
- **002 before 003** — The pointer gate (002) removes transforms from hover rules; the reduced-motion fix (003) also zeros transforms. Applying 002 first means 003 has less to override.
- **003 after 001 + 002** — The surgical reduced-motion block is most effective after the base transitions are already specific (001) and hover transforms are already gated (002).
- **005 independent** — Navbar fix is isolated to one line and has no dependency on any other plan. Can be executed any time.
- **004 last** — Adds a new Framer Motion dependency on a component. Best done after the CSS-only fixes are verified and clean.

## Dependencies

- Plan 004 requires Framer Motion to already be installed (`package.json` confirms it is).
- Plans 001–003 all touch `app/globals.css` — do not execute them simultaneously. Apply sequentially and run `npm run build` after each.
- Plans 004 and 005 touch `components/layout/Navbar.tsx` — do not execute simultaneously.
